<h1>How To Update Your Company Computer</h1>

<h2>Overview</h2>
This article explains how employees can manually check for and install operating system updates on company-managed devices. <br> <br>

**Windows 11**
1. Open the **start** menu.
2. Navigate to **settings**.
3. Navigate to **Windows Update**.
4. Select **Check for Updates**.
5. **Follow the prompts** to install available updates.

**MacOS**
1. Open **System Settings**.
2. Navigate to **General**.
3. Navigate to **Software Updates**.
4. Select **Check for Updates**.
5. **Follow the prompts** to install available updates.

**If you cannot install the update** <br>
If an update fails to install or your computer displays an error message:
* Restart your computer and try again.
* Make sure the computer is connected to the internet.
* Ensure the device has sufficient storage space.
* Contact the **IT Service Desk** if the problem continues.

**Applies to: Windows, MacOS**
